# KOP Lescure — le classement des Girondins

App fun pour classer nos joueurs préférés des Girondins (Loïc, Pierre, Patrick-Abdou).

👉 **https://vlloic.github.io/kop-lescure/**

- **Duels** : joueur A ou joueur B, jusqu'à obtenir un classement complet (~180 duels pour 48 joueurs, sauvegardé au fur et à mesure). « 🤷 Je passe » (3 jokers) écarte un joueur qu'on ne connaît pas.
- **Partage** : chacun copie son lien et le poste dans le groupe KOP Lescure ; l'ouvrir ajoute son classement.
- **Classement commun** : moyenne des rangs.
- **Le vestiaire** : stats fun (pomme de discorde, chouchous, compatibilité, XI de légende…).

Aucun compte, aucun serveur : tout est stocké dans le navigateur.

Modifier la liste des joueurs : `joueurs.js`.
